gitbug

Every GitHub repository you can access, in one searchable list.

  1. Create a classic token with the repo and read:org scopes. Set Expiration to "No expiration" if you don't want to do this again.
  2. If an org uses SAML SSO, click Configure SSO next to the token and authorize it for that org.
  3. Paste it here. It stays in this browser and is only sent to api.github.com.
